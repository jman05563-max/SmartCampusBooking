
# Smart Campus Resource Booking System

## Description
A Python application that allows lecturers to book campus resources. Campus administrators can manage resources, while system operators can view campus booking reports.
https://github.com/jman05563-max/SmartCampusBooking.git
## Technologies Used
- Python
- Tkinter
- SQLite

## Features
- User registration and login
- Role-based access for lecturers, campus administrators, and system operators
- Three campuses: Pretoria, NewTown, and Centurion
- Resource booking with campus-specific booking rules
- Booking history and cancellation
- Resource management
- Campus booking reports

## How to Run
1. Open the project in PyCharm.
2. Make sure Python is installed.
3. Open `main.py`.
4. Run `main.py`.
